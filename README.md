# AIMario — 《超级马里奥兄弟 3》风格致敬复刻

一个**零依赖**的网页游戏：原生 JavaScript + Canvas，所有像素画面由代码绘制、所有音乐音效由 WebAudio 实时合成——仓库里没有一张图片、没有一个音频文件、没有一个 npm 依赖。

> ⚠️ 本项目是对经典游戏设计方法论的学习性致敬。不含任何任天堂素材（图形、音乐、旋律均为原创"致敬风"设计），非商业用途。

## 快速开始

```bash
git clone https://github.com/xlwangcs/AIMario.git
cd AIMario
node tools/serve.mjs      # 打开 http://127.0.0.1:8000/
```

（ES modules 需要经 HTTP 加载，所以要起这个 20 行的零依赖静态服务器；任何静态服务器都行。）

## 操作

| 键 | 功能 |
|---|---|
| ← → ↑ ↓ / WASD | 移动（地图上选路） |
| Z / 空格 | 跳跃（按住跳更高）；飞行中连按拍尾巴 |
| X / Shift | 按住跑步蓄 P 表；狸猫=尾巴攻击；火焰=火球 |
| ↓ | 蹲下（大个子）；管道口=进入管道；白块上蹲 1 秒有惊喜 |
| C | 世界地图上打开道具库存 |
| Enter | 确认 / 暂停 |
| F1 / M | 调试叠层 / 静音 |

也支持标准手柄（Xbox 布局）。

## 实现了什么（SMB3 的身份特征）

- **三档速度 + P 计量表**：走 1.5 → 跑 2.5 → P 速 3.5 px/帧（NES 原值），全速跑约 1 秒蓄满 7 格
- **分档跳跃 + 重力二值化**：跑得越快跳得越高；按住跳上升重力小
- **四形态即动词**：小 / 超级（碎砖·蹲）/ 火焰（火球）/ **狸猫（尾击 + 缓降 + 满 P 表飞行 255 帧）**
- **受伤先降超级**（SMB3 的宽容规则），星星无敌、连踩得分链 100→…→8000→1UP
- **世界地图战役**：节点路网、要塞通关炸开、蘑菇屋、**道具库存**（地图上随时变身）
- **终点卡片**：蘑菇/花/星轮转抽取，集满 3 张结算奖命（三同款大奖）
- 斜坡、单向平台、音符块、隐藏块、白块背景层、管道与地下奖励室、Boom-Boom 要塞 BOSS
- 15 种敌人、35 种合成音效、14 首原创芯片风 BGM、localStorage 战役存档

## 工程结构

```
index.html            双击可看（但请用 HTTP 起）

tools/                静态服务器 / import 图校验 / 美术预览页
```

## 测试

```bash
npm test                        # node --test tests/
# 或逐文件（无子进程环境）:
node tests/physics.test.mjs
```

物理测试把"手感"锁进断言里：滑行必须 ≥30 帧（惯性即张力）、轻点跳 ≈ 满跳 45%、P 表蓄满 40~80 帧……改坏手感会直接红灯。
关卡校验测试会自动检查"同屏敌人密度 ≤ 阈值"和 1-1 教学关的方法论落实（首敌必须是栗宝宝、必须存在安全坑与致死坑）。
