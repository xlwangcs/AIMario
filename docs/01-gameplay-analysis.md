# 《超级马里奥兄弟 3》玩法解剖与复刻设计分析

> 本文是 AIMario 项目的**第一份产物**：在写任何一行游戏代码之前，先把「SMB3 到底好玩在哪、由哪些机制咬合而成」拆到可编码的粒度。
> 设计原则部分基于随项目提供的《经典马里奥游戏设计理念调研报告》（下称《调研报告》，2026-08-20），机制数值部分见 `docs/research/smb3-mechanics.md`。

---

## 0. 一句话结论

初代《超级马里奥兄弟》卖的是**「一条线上的跳跃手感」**；《超级马里奥兄弟 3》(1988) 卖的是
**「一张地图上的资源战役」**——它把「手感」保留为内核，在外面套了三层新结构：**形态即动词**、**关卡即语法**、**地图即战役**。
复刻它，光把马里奥跳得像不够；必须把这三层一起做出来，否则做出来的只是"又一个平台跳跃 demo"。

---

## 1. 玩法的五个时间尺度

好玩不是一个整体感受，而是五个不同时间尺度上各自成立、并且**互相供能**的循环。SMB3 是这五层全部咬合的教科书。

| 尺度 | 时长 | 玩家在做的事 | SMB3 的核心机制 | 失败的代价 |
|---|---|---|---|---|
| **帧层** | 16ms | 按键 → 位移反馈 | 子像素惯性、分档跳跃、转向打滑 | 手感不对，一切白搭 |
| **秒层** | 1–5s | 通过一个「挑战单元」 | 一坑 / 一敌 / 一组砖块 | 掉一次血 |
| **分钟层** | 30–120s | 打通一关 | 起承转合的关卡编排 + 终点卡片 | 掉一条命 |
| **小时层** | 20–60min | 攻克一个世界 | **世界地图 + 道具库存 + 要塞开路** | 掉进度（但可重来） |
| **元层** | 跨周目 | 优化路线 / 找秘密 | 笛子、隐藏区、白蘑菇屋、卡片经济 | 无（纯奖励） |

> **实现启示**：项目的开发顺序必须**自内向外**——帧层（物理）→ 秒层（碰撞与敌人）→ 分钟层（关卡）→ 小时层（地图）。
> 这也正是《调研报告》第二节的"后置设计"：先做有趣的内容，最后回头做 1-1 的教学。

## 2. 核心循环

```
        ┌──────────────── 世界地图：规划 ────────────────┐
        │  选路线 → 用库存道具变身 → 进入关卡节点        │
        ↓                                                │
   关卡内循环（分钟层）                                   │
   ┌─→ 观察前方挑战单元                                   │
   │      ↓                                              │
   │   选择动词（走/跑/跳/踩/扔火球/尾巴扫/飞）           │
   │      ↓                                              │
   │   即时反馈（音效 + 弹跳 + 得分数字 + 屏幕震动）      │
   │      ↓                                              │
   │   收益（金币/道具/捷径） 或 惩罚（降级/掉命）        │
   │      ↓                                              │
   └── 安全区喘息 → 下一个挑战单元 → 终点卡片            │
        ↓                                                │
        └────── 结算：卡片 / 库存 / 开路 ────────────────┘
```

这个循环的驱动力是《调研报告》第五节引用的宫本茂对"互动的乐趣"的定义：
**想法 → 执行 → 反馈**的闭环。因此**反馈的即时性与丰富度**（音效、粒子、得分弹字、敌人被踩扁的形变）是必须实现的一等公民，不是"以后再加的美化"。

## 3. 第一层：帧层——马里奥物理，为什么"不好停下来"是设计而非缺陷

### 3.1 三档速度是 SMB3 的最大手感革新

初代只有「走 / 按 B 跑」两档。SMB3 引入了第三档：**P-speed（P 计量表满速）**，并把它做成了**需要维持的状态**。

| 状态 | 触发 | 感觉 | 玩法后果 |
|---|---|---|---|
| 走 | 方向键 | 精确、可微调 | 用于窄平台走位 |
| 跑（按住 B） | 持续按住 | 开始打滑 | 用于跨越大坑 |
| **P-speed** | 全速跑约 1 秒，P 表蓄满 7 格 | 极快、几乎停不下来 | **狸猫起飞 / 冲过整段关卡 / 撞碎多块砖** |

关键设计洞察：**P 计量表把"高速"从瞬时属性变成了需要经营的资源**。
玩家为了保住 P 表，会主动选择"不减速的路线"，于是**关卡设计者获得了一根新的操纵杆**：给一条长直跑道，玩家自己就会想去跑满它；跑满了就能飞起来看到上层的秘密。这就是《调研报告》里"用形式表现功能"的进阶版——**用地形表现意图**。

### 3.2 惯性即张力

《调研报告》第五节：马里奥"松键后不立即停下而有减速阶段"，"**无法干净利落地停下**"本身制造了落坑/撞敌风险，"操作缺陷被转化为玩法张力"。

因此实现时**绝不允许**为了"手感精准"而把摩擦力调成瞬停。必须实现：
- 分离的 **地面加速度 / 空中加速度 / 摩擦减速度 / 转向（skid）减速度**（转向要比自然摩擦更强，并播放打滑音效与 skid 姿态——这是形式表现功能）；
- **子像素累加**（位置与速度都用浮点/定点保存，渲染时才取整），否则低速微调会丢失，手感立刻变"数字化"；
- 空中**保留水平惯性**但降低操控权（空中加速度 < 地面加速度）。

### 3.3 分档跳跃与"重力二值化"

SMB3 的起跳初速度**随水平速度分档**（跑得越快跳得越高越远），且**按住 A 时重力更小、松开 A 立刻切换到大重力**——这就是"可变跳跃高度"的实现方式。

这两条合起来，让「跳跃」这一个按键承载了**连续的表达空间**：轻点=小跳踩敌，助跑长按=极限远跳。
《调研报告》第一节"按键响应速度 > 动画平滑度"在此处的具体要求是：
**起跳必须在按下 A 的同一帧产生位移**，不允许有"预备动画"帧。同理，转向、尾巴攻击、扔火球都必须 0 帧前摇。

### 3.4 帧层验收清单（手感自检）

- [ ] 从静止到走路最大速度约 0.5 秒，到跑步最大速度约 1 秒，P 表蓄满再约 1 秒；
- [ ] 松开方向键后有明显滑行距离，且能在滑行中转向打滑；
- [ ] 轻点 A 的跳跃高度 ≈ 长按的 45%~55%；
- [ ] 全速起跳的水平跨越距离 ≥ 4.5 格（能过 4 格宽坑），走路起跳 ≤ 3 格（过不去）；
- [ ] 所有操作 0 帧前摇；
- [ ] 落地、撞头、踩敌、撞墙都有独立音效与视觉反馈。

## 4. 第二层：形态即动词

初代的道具是"血量条"（小 → 大 → 火）。SMB3 的道具是**动词表**：每个形态给你一个**新的与世界交互的方式**，而不只是多一格血。

| 形态 | 新增动词 | 能解决的关卡问题 | 形式表现功能 |
|---|---|---|---|
| 小马里奥 | （基线）跑、跳、踩 | — | 体积小，可进窄缝 |
| 超级马里奥 | 撞碎砖块、蹲下 | 打开砖墙、钻矮洞 | 体型变大 = 更强也更容易被打 |
| 火焰马里奥 | 远程攻击 | 清远处敌人、点燃某些机关 | 白衣红背带 = 一眼可辨 |
| **狸猫（超级叶子）** | **尾巴横扫**、**缓降**、**P 表飞行** | 打碎头顶砖/击退敌人/**飞到关卡上层的秘密区**/长时间滞空过大坑 | 尾巴与耳朵 = 明示"我能飞" |
| 天狗（Tanooki） | 变石像（无敌下砸） | 硬穿弹幕 | 全身套装 |
| 青蛙 | 水中自由游动 | 水关 | 蛙服 |
| 锤子兵 | 扔锤子、龟壳防火 | 硬碰硬 | 龟壳 |

**这是 SMB3 玩法深度的主要来源**：同一个关卡，用不同形态进去，就是不同的关卡。狸猫的"飞行"甚至能**破坏**关卡的线性结构（直接飞过整关 / 飞上云端隐藏区）——任天堂选择**允许**这种破坏，因为它服务于《调研报告》第一节"面向新玩家"与第四节"可重来"：卡关的玩家可以用道具把难度降下来。

### 4.1 受伤降级链（与初代不同，必须核实并实现）

SMB3 的规则不是"火焰→小"，而是**任何强化形态受伤都先降回超级马里奥**，再受伤才变小。
这是一条**纯粹的挫败感缓冲**设计（《调研报告》四·1"可重来"原则的机制化）：它让玩家敢于用高级形态去冒险。

### 4.2 库存（Inventory）——把难度调节权交给玩家

SMB3 允许把道具**存起来**，在世界地图上随时使用。这条机制的意义远超便利性：

- 它把"我打不过这关"从**失败**变成了**资源问题**（去蘑菇屋拿道具 / 存三片叶子）；
- 它让玩家**自己**调节难度曲线，完美命中《调研报告》一·4"面向新玩家而非只服务硬核"；
- 它创造了元层策略：什么时候用、留给哪一关、要不要为了刷道具重打简单关卡。

**结论：库存不是可选功能，是 SMB3 身份的一部分，必须实现。**

## 5. 第三层：关卡即语法

### 5.1 挑战单元（challenge）与安全边界

《调研报告》二·6 给出了可直接执行的关卡语法（源自对《超级马里奥世界》方法论的译介，同样适用于 3）：

1. **基本单元 = 挑战**：一小段"必须一次性完成"的任务；
2. 挑战被**安全区**包围，让玩家喘息、观察、准备；
3. 难度靠**进化（evolution）**：在已有元素上**加一个质变元素**，而不是堆量；
4. **同屏最多 3 个障碍**，超过就要警惕难度失控。

### 5.2 一个关卡的"起承转合"

```
起：引入本关的核心元素（单独、安全、可观察）
承：把核心元素与旧元素组合（加一个变量）
转：变形/加压（速度、密度、地形反转、或引入新敌人）
合：小高潮 + 释放（一段爽快的连踩/长跑/大量金币）→ 终点
```

**每关必须有一个"本关主题"**（一种敌人、一种地形、一种节奏）。这是 SMB3 区别于初代的另一点：初代的关卡是"通用平台跳跃"，SMB3 的每关几乎都在教一个新玩具（斜坡、白块、音符块、Boom-Boom 要塞、飞船甲板……）。

### 5.3 隐性教学（Mario 101）——必须复刻的方法论

《调研报告》二·1~4 的关键事实：

- 1-1 是**开发末期**才做的，用于教学与难度平衡（**后置设计**）；
- **完全不用文字**：靠敌人位置、问号砖块、蘑菇弹出反弹等布局，让玩家数秒内自己领悟；
- 第一个敌人是专门"发明"的**栗宝宝**（因为慢慢龟的"踩+踢"两步操作对新手不直观）；
- **双坑教学**：第一个坑有底、可安全练习远跳；第二个坑几乎一样但会死。

**我们的 1-1 必须逐条落实这四点，并写成注释标注每个物件的教学意图。**

### 5.4 观察式试玩 → 我们的替代方案

《调研报告》第三节：宫本茂的核心方法是"递上手柄、默默站在背后观察"，且"问卷说有趣 ≠ 实际表情有趣"。
我们没有真人试玩场，但可以**用可观测的行为数据替代问卷**：

> 在引擎里内建一个 **遥测/回放钩子**（`debug.telemetry`）：记录每次死亡的位置、每个挑战单元的重试次数、P 表满速持续时长、道具使用点。
> 关卡调优时看这份热力数据，而不是凭"我觉得这关不难"。

这是《调研报告》七·3 的直接落地，也是本项目区别于普通复刻的工程亮点。

## 6. 第四层：地图即战役

SMB3 世界地图是整个系列的分水岭。它带来的玩法价值：

| 地图元素 | 玩法功能 | 情绪功能 |
|---|---|---|
| 节点与路径 | 把线性关卡变成**有拓扑的战役** | 看得见进度 |
| 分叉与捷径 | 玩家**有选择** | 主动感 |
| 要塞（Fortress）+ Boom-Boom | 通关后**炸掉要塞开新路** | 阶段性胜利感 |
| 蘑菇屋（Toad House） | 免费道具 | 喘息与奖励 |
| 黑桃 N-Spade 配对 | 小游戏换命 | 变节奏 |
| 巡游的锤子兵 | 地图上也有**动态威胁** | 紧张感延伸到地图 |
| 管道 / 笛子 | 跳跃式移动 | 秘密与掌控 |
| 飞船（Airship） | 世界终局 BOSS | 高潮 |

关键点：**地图让"失败"变得可承受**。关卡里死了，你回到地图，还带着库存，还记得路线——这正是"可重来"原则在系统层的表达。

## 7. 第五层：经济与风险—回报

SMB3 的每一个奖励都挂着一个"要不要冒险"的问题：

- **连续踩踏得分序列** 100→200→400→800→1000→2000→4000→8000→1UP：鼓励玩家**不落地地连踩一串敌人**——一个高风险高回报的表演动作；
- **金币** 100 枚 → 1UP：把"贪心吃金币"变成理性投资；
- **隐藏砖块 / 隐形 1UP / 云端秘密区**：奖励好奇心（《调研报告》八节承认这块是调研缺口，但机制事实明确）；
- **终点卡片**（三张相同 = 大量奖命）：把"通关"本身变成一次小赌博，并给了重打简单关卡的理由；
- **蹲进白块进背景层**：奖励观察力（"总会有人停下来看"，《调研报告》四·3）。

**设计守则**：每个奖励必须**看得见但不免费**。看得见 → 产生欲望；不免费 → 产生技巧表达。

## 8. 「用形式表现功能」信号表（实现清单）

《调研报告》二·5：带刺的龟表示不可踩、被看的 Boo 会脸红。我们必须建立同等严密的信号系统：

| 玩家需要知道的事 | 视觉信号 | 听觉信号 |
|---|---|---|
| 这个敌人不能踩 | 尖刺（Spiny）、火焰（Podoboo）、骨头（Dry Bones 踩了会重组） | 撞击音（bump）而非踩踏音 |
| 这个砖块能撞碎 | 砖纹 + 撞击时抖动 | `breakBlock` 碎裂音 |
| 这个块已用过 | 变成暗色实心块 | `bump` 闷响 |
| 这个块有东西 | 问号闪烁动画 | 撞出时 `powerup`/`coin` |
| 我处于 P-speed | HUD 的 P 表全亮闪动 + 马里奥 run 姿态 | `pMeterFull` 上行提示音 |
| 我能飞了 | 狸猫尾巴 + 起飞时 `fly` 姿态 | `flap` 拍打音 |
| 我快没时间了 | HUD 时间变红 | `timeWarning` 加速心跳音 |
| 我刚拿到什么 | 道具图标 + 得分弹字 | 每种道具独立音效 |
| 平台可从下方穿过 | 木质单向平台的**镂空侧面** | 落地 `land` 音 |

> 这张表是"响应优先于华丽"（《调研报告》一·2）的具体施工图：宁可少一层视觉特效，也不能少一条状态信号。

## 9. 难度与挫败感

| 原则（出自《调研报告》） | SMB3 的机制 | 我们的实现决策 |
|---|---|---|
| 反对"从零重来" | 死亡回到世界地图节点，库存保留 | 关卡内**中点旗**（SMB3 原版没有，但《银河》的"关卡中间保存点"结论支持加）→ **做成可开关的辅助选项**，默认关闭以保留原味 |
| 记忆点 vs 挫败感的平衡 | 关卡短（30–90 秒） | 每关目标时长 45–90 秒 |
| 面向新玩家 | 库存道具、狸猫飞行可跳过难段 | 全部实现；额外提供"练习模式"（无限命） |
| 难度靠观察校准 | 观察式试玩 | 内建死亡热力遥测 |
| 总会有人停下来看 | 大量无功能细节动画 | 敌人被踩扁的形变、金币旋转、通关后 Toad 的动作等细节不省略 |

## 10. 与《调研报告》17 条原则的对照总表

| # | 原则 | 本项目的落地点 |
|---|---|---|
| 1 | 趣味优先且尽早验证 | **阶段 2 结束时必须先有一个"只有一个平台和一个马里奥"的可玩手感 demo**，手感不过关不往下做 |
| 2 | 物理服从直觉 | 子像素惯性 + 分档跳跃 + 宽容的碰撞盒（脚下判定略宽、头顶判定略窄） |
| 3 | 响应压过华丽 | 0 帧前摇；渲染与逻辑分离，逻辑固定 60Hz |
| 4 | 游戏是产品不是艺术品 | 零依赖、无构建、双击即玩、README 三行上手 |
| 5 | 面向新玩家 | 库存、辅助选项、隐性教学的 1-1 |
| 6 | 教学是后置设计 | **1-1 放在阶段 6 最后写**，前面先做 1-3 这种"有趣关卡" |
| 7 | 不用文字的环境教学 | 1-1 全程零文字提示 |
| 8 | 为新手发明敌人 | 第一个敌人必须是可一脚踩扁的栗宝宝，慢慢龟延后到 1-2 |
