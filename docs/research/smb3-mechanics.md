# SMB3 机制数值参考（实现取值依据)

> 本文为 AIMario 的数值取值依据。原计划由检索代理产出全程带来源引文的考证版，
> 该代理多次中断，本文改由主实现者基于长期流传的社区反汇编/速通资料整理，
> **置信度如实标注**；与本项目实际取值的差异在最后一节说明。
>
> 主要参考（可自行核对）：
> - [captainsouthbird/smb3 反汇编工程](https://github.com/captainsouthbird/smb3)（NES 原码注释版）
> - [TASVideos: SMB3 Game Resources](https://tasvideos.org/GameResources/NES/SuperMarioBros3)（速通社区整理的速度/机制表）

## 1. 水平速度（NES 单位：subpixel/frame，16 subpixel = 1 px）

| 机制 | NES 原始值 | px/帧 | px/秒 @60fps | 置信度 |
|---|---|---|---|---|
| 走路最大速度 | 0x18 | 1.5 | 90 | 高（多源一致） |
| 跑步(B)最大速度 | 0x28 | 2.5 | 150 | 高 |
| P-speed 最大速度 | 0x38 | 3.5 | 210 | 高 |
| 地面加速度 | ≈0x01/f | ≈0.0625 | — | 中（不同资料 0x00.8~0x01） |
| 摩擦减速度 | ≈0x01/f | ≈0.0625 | — | 中 |
| 转向(skid)减速度 | > 摩擦（约 2~3 倍） | ≈0.15 | — | 低（凭手感复核） |

## 2. 跳跃与重力

- 起跳初速**随水平速度分档**：静止跳约 0x38（3.5 px/f），全速跳更高（约 0x40=4.0）。分档表存在是**高置信**事实，具体每档数值为**中置信**。
- **重力二值化**：按住 A 上升期重力小、松开后重力大（SMB 系列通用实现）。置信度：高（实现方式）；具体数值：低。
- 终端下落速度：约 4.0 px/f（0x40）。置信度：中。
- 狸猫缓降时下落约 1.0 px/f。置信度：中。

## 3. P 计量表

| 项 | 值 | 置信度 |
|---|---|---|
| 格数 | 7（HUD 显示 6 箭头 + P 徽章） | 高 |
| 蓄满耗时 | 全速跑约 1 秒（约每 8 帧 +1） | 中 |
| 衰减 | 显著慢于蓄满（约每 16~24 帧 -1） | 中 |
| 跳跃中 | 保持不掉（这是"助跑-起跳-续飞"成立的前提） | 高 |
| 飞行时长 | 起飞后 **255 帧 ≈ 4.25 秒**（帧计数器 0xFF） | 高（反汇编常引） |

## 4. 形态规则

- 形态：小 / 超级 / 火 / 狸猫（浣熊）/ 天狗 / 青蛙 / 锤子。置信度：高。
- **受伤降级**：SMB3 中强化形态（火/狸猫等）受伤**先降回超级**，超级受伤降为小。置信度：高（与 SMB1 直接变小不同，此为 3 代标志性宽容设计）。
- 受伤无敌约 2 秒；星星无敌约 10 秒。置信度：中。
- 尾巴攻击：短冷却、判定在身前下方；可击杀多数步行敌、击碎砖块。置信度：高（行为），帧数：低。
- 火球：同屏最多 2 颗，弹地前进。置信度：高。

## 5. 道具库存与地图

- 库存在地图随时使用，容量远大于 1（原版 28 格分页显示；本项目取 8）。置信度：高（存在性）。
- 蘑菇屋送道具；要塞通关摧毁并开路；锤子兄弟在地图上游走；这些为**高置信**的结构事实。
- 白蘑菇屋等收集触发彩蛋：存在（高），细则未实现。

## 6. 经济与结算

| 项 | 值 | 置信度 |
|---|---|---|
| 连踩得分链 | 100→200→400→800→1000→2000→4000→8000→1UP | 高 |
| 金币 | 100 枚 = 1UP | 高 |
| 关卡时限 | 多为 300，个别 200/400 | 高 |
| 时间流速 | 明显快于现实秒（约 0.5~0.7 现实秒/单位） | 中 |
| 终点卡片 | 蘑菇/花/星轮转；集 3 张结算：三蘑菇 2UP、三花 3UP、三星 5UP、混搭 1UP | 高 |
| 卡片即得分 | 蘑菇 800 / 花 1600 / 星 3200（本项目取值） | 低（原版为固定分值，具体额度记忆） |

## 7. 敌人行为要点（高置信的行为学，数值为工程取值）

- 栗宝宝：直走，坠崖不回头；踩=死。
- 慢慢龟绿：直走坠崖；红：崖边回头。踩→壳；壳可踢（约 3.0~3.75 px/f），滑行壳杀敌并有独立得分链；静置若干秒后苏醒。
- 飞龟绿：蹦跳前进；红：定域垂直巡航。踩掉翅膀。
- 铁甲龟：防火球。刺猬：不可踩。骨头龟：踩塌后约 6 秒重组、防火。
- 食人花：玩家贴近管口时不出头（仁慈规则）。
- 子弹比尔：直线飞行，可踩；炮台近距离不发射。
- Boom-Boom：踩 3 次退场，每次受击后短暂缩壳并提速。置信度：高（3 次与提速），细节动作：中。

## 8. 本项目实际取值 vs 原版

本项目**明确不追求逐帧还原**（见 `01-gameplay-analysis.md` §11 反目标），取值原则：
1. 三档速度 1.5 / 2.5 / 3.5 px/f **照抄原版**（这是手感身份，不能动）；
2. 加速度/摩擦按"静止→走满 0.5s、→跑满 1s、滑行 ≈3 格"的体验目标标定（`src/game/constants.js`）；
3. 重力对 (0.117 / 0.34) 按"满跳 ≈3.6 格、轻点 ≈45%"标定，并写入单元测试锁定（`tests/physics.test.mjs`）；
4. 飞行 255 帧、7 格 P 表、连踩得分链、卡片结算等**结构性数值照抄原版**；
5. 所有取值都能通过修改 `constants.js` 单点调整——常量文件就是本项目的"手感控制台"。
